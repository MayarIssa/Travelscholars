# Travel Scholars

My shortlist of master's programs in AI, Computer Science and Data Science for 2027:

- Germany: public universities with no tuition that accept an MOI letter
- USA and Canada: funded programs with a stipend that accept an MOI letter
- Worldwide: fully funded scholarships with MOI or no English test

Each program shows deadlines, requirements, documents, what I pay the university, the stipend, the money to bring from Egypt and the overall cost. The checklist and application status are saved in the browser.

Static site (HTML, CSS, JavaScript). Data lives in `data.js`.
